## 🐛 Common Issues & Fixes

### Issue: Text is hard to read
**Fix:** Increase contrast in CSS variables

### Issue: Shadows not visible
**Fix:** Increase shadow opacity or spread

### Issue: Gold color too light
**Fix:** Use --zenara-gold-dark instead

### Issue: Cards blend with background
**Fix:** Increase border visibility or add shadow

### Issue: Mobile menu is dark
**Fix:** Check .nav-menu background color
